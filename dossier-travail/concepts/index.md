# Concepts

Une fiche par notion technique, rédigée avec ses propres mots.

## Comment ajouter une fiche

Dans Obsidian : créer une note vide dans `concepts/`, puis `Cmd+P`
(Windows : `Ctrl+P`) → *Insérer un modèle* → `fiche concept — modèle`.
Le modèle lui-même n'est pas à modifier.

Nom de fichier en minuscules, sans accents, avec des tirets :
`reseaux-de-neurones.md`, `tokenisation.md`.

La liste ci-dessous se construit automatiquement.

```{toctree}
:maxdepth: 1
:glob:

*
```
