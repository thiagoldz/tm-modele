# Veille technologique

Le séminaire demande de suivre l'actualité IA **2 à 3 fois par semaine**. Cette
section sert à en garder trace.

## Ce qu'il faut noter

Pour chaque élément : la date, la source, et ce qu'on en retient.

Format des sources, le même que dans les fiches :

```
Vidéo   : Auteur, « Titre », YouTube, JJ.MM.AAAA. URL
Article : Auteur, « Titre », Nom du site, JJ.MM.AAAA. URL
```

## Comment s'organiser

Un fichier par thème plutôt qu'un fichier unique : `videos.md`, `articles.md`,
`modeles.md`… Ils apparaissent automatiquement dans la liste ci-dessous.

Les chaînes et sites suivis par le séminaire sont listés dans sa page Notion.

```{toctree}
:maxdepth: 1
:glob:

*
```
