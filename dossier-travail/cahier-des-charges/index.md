# Cahier des charges

Premier élément exigé du dossier de travail : une description claire et
concise du projet — ses objectifs, sa problématique et les résultats attendus.

## Ce que le cahier des charges doit contenir

- la description de la tâche à automatiser, par un agent IA ou par un système
  multi-agents ;
- la motivation personnelle pour le choix de cette tâche ;
- les technologies et outils prévus ;
- les critères de réussite et les indicateurs de performance qui permettront
  d'évaluer le projet ;
- la gestion de la souveraineté numérique : où tourne le système (en local ou
  dans un cloud souverain, par exemple Infomaniak, Scaleway ou OVH) et comment
  les données sont gérées ;
- une évaluation des risques de sécurité et de confidentialité liés au projet,
  et les mesures prévues pour les atténuer.

Le détail est dans le manuel du séminaire, section *Obsidian → 4. Dossier de
travail*.
